About Unsething

Product

Unsething is a DICOM image viewer built on open source medical imaging software, including code derived from Horos and OsiriX and other open source libraries. Source code and third-party license notices are provided as required by the applicable open source licenses.

Intended use

Unsething is intended for local DICOM storage, retrieval, routing and image review. It is not intended for primary diagnostic interpretation unless supplied in a separate configuration regulated as a medical device.
