# Contributing

Build and test instructions are in [README.md](README.md) and [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

Keep changes focused and explain the behavior they fix, with relevant validation. Preserve upstream copyright and license notices. When changing a dependency, update its locked revision, archive hash and source patch together. Do not commit downloaded dependency trees or build outputs.

Use synthetic or appropriately anonymized data in issues, pull requests and tests. Never include patient archives, identifiable screenshots, credentials, private keys or signing certificates. Application plugins are distributed separately and must not be added to this repository.

Contributions are made under the applicable existing license of the files being changed. Adding a third-party component requires retaining its license and updating the dependency notices.
